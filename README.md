# AI-Buggy 🐛

## Introduction

AI-Buggy is an AI-powered personal assistant designed to help students and researchers manage scattered information, organize tasks, and receive intelligent reminders.

## Motivation

Modern people receive information from many different sources, including messages, emails, documents, and schedules. However, important tasks are easily forgotten.

AI-Buggy aims to transform scattered information into organized actions.

## Core Features

- 🐛 AI smart reminder
- 📌 Automatic task extraction
- 📊 Eisenhower Matrix task management
- ⏰ Intelligent scheduling
- 📖 Daily review
- 🎯 Personal goal management
